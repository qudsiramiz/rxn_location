# rxn_location

Statistical comparison between X-line location predicted by various models for dayside terrestrial magnetopause.

## Installation

You can install the package via pip:

```bash
pip install rxn_location
```

## Quick Start

You can find examples in the `examples/` directory of the GitHub repository.

```python
from rxn_location import rx_model
```

## Interactive GUI

`rxn_location` features a powerful interactive Streamlit GUI to visualize your data, test for Jet Reversals, run models dynamically, and easily generate aggregated statistical plots.

To launch the app locally:
```bash
streamlit run src/rxn_location/app.py
```

Check out the [GUI Usage Guide](gui_usage.md) for full details on how to use the interactive application!
